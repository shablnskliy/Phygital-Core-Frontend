ДЕМО-СТРАНИЦЫ PHYGITAL CORE

Проект: папка front new, рядом с package.json.

После npm.cmd run dev откройте адрес, показанный терминалом:
- /admin-demo — демо-админка с созданием/редактированием/удалением турниров;
- /visual-check — заполненный пример страницы турнира;
- /visual-check?id=ID — просмотр созданного в демо-админке турнира.

КАК ВЫКЛЮЧИТЬ ВСЕ ДЕМО-СТРАНИЦЫ

В src/shared/config/demo.ts установите:
export const DEMO_PAGES_ENABLED: boolean = false;

Перезапустите dev-сервер. Для production выполните новую сборку.
Оба маршрута начнут возвращать 404. Реальная админка /admin и обычные
страницы турниров продолжат работать. Чтобы включить снова, верните true.

ГДЕ НАХОДИТСЯ КОД

app/admin-demo/page.tsx                 — маршрут и проверка переключателя;
app/(public)/visual-check/page.tsx      — маршрут примера и проверка переключателя;
src/pages/demo-admin/                  — композиция демо-админки;
src/pages/demo-tournament/             — композиция примера/предпросмотра турнира;
src/features/demo-sandbox/             — тестовые данные и отдельное локальное хранилище;
src/shared/config/demo.ts              — общий переключатель;
src/app/styles/demo.css                — оформление только демо-страниц;
app/layout.tsx                        — подключение demo.css.

Демо переиспользует существующие TournamentsAdmin, TournamentPageEditor и
TournamentDetail через явные sandbox/preview-параметры. Они остаются нужны
для реального сайта: удалять эти общие компоненты целиком не нужно.
Для отключения достаточно переключателя; удаление файлов не обязательно.

ДАННЫЕ И БЕЗОПАСНОСТЬ

Ключ хранилища: pc-admin-demo-v1. Демо не меняет jwt_token, реальные команды,
партнёрские события или страницы реальных турниров и не выдаёт права ADMIN.
Реальная админка сохраняет прежнюю проверку авторизации.
Демо-данные видны только на том же адресе сайта и в том же браузере.
Пример и его редактор используют только демо-хранилище; отправка заявок
с демонстрационной страницы на backend отключена.
Выключение демо не удаляет уже сохранённые демо-данные автоматически.
