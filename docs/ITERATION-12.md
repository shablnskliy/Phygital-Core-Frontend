# Phygital Core — итерация 12

Дата: 7 октября 2026 года. Правки 129–168.

## Изменения

- Прокрутка остаётся нативной. Убрано глобальное `scroll-behavior: smooth`; Scroll Snap и обработчиков wheel/touch нет. Добавлен стабильный gutter полосы прокрутки.
- Модальное окно блокирует прокрутку и устанавливает фокус один раз при открытии. Обновление полей, loading и callback больше не запускает повторную фокусировку. При закрытии фокус возвращается без прокрутки страницы.
- Общий PageHeader: индекс, крупный заголовок с заполненной и контурной частью, короткая подпись, описание, тематическая сцена. Анимации появления и фонового движения учитывают prefers-reduced-motion. Главная использует прежний Hero.
- Турниры, FAQ и контакты используют существующие локальные изображения PNG/WebP внутри композиции. Команды используют связанные узлы/аватары; правила — щит и линии регламента. Изображения сохраняют пропорции через object-fit: contain.
- Страница команд: сетка 3/2/1 колонок, монограммы, капитан, количество участников, поиск по названию, пустые результаты, окно состава. Капитан может приглашать, удалять обычных участников, передавать капитанство и удалять команду с подтверждением. Права проверяются и в общем store.
- Смена капитана допускает только игрока из состава. Удаление текущего капитана запрещено до передачи роли. Удаление команды отменяет ожидающие приглашения. После удаления игрока его можно пригласить снова.
- Правила: на desktop навигация слева и одна контентная панель справа; на mobile один раскрытый accordion. Добавлены прогресс, Назад/Далее и клавиатурная навигация стрелками/Home/End.
- Текст всех шести разделов правил сохранён без изменений; изменено только его визуальное разбиение на абзацы.

## Проверки

- Production build, TypeScript (`tsc --noEmit`) и ESLint завершились успешно.
- Сетка команд проверена в браузере на 1920, 1440, 1366, 1024, 768 и 390 px. Горизонтальное переполнение отсутствует; поиск и создание команды видимы.
- Проверены поиск по названию, пустые результаты, открытие и закрытие состава на mobile, восстановление прокрутки после закрытия.
- Проверены гостевой запрос входа, создание тестовой команды, поиск зарегистрированного игрока, отправка приглашения и блокировка повторной отправки.
- Проверены принятый состав, уведомление о присоединении и отсутствие капитанских действий у обычного участника.
- Передача капитанства проверена через UI: новый капитан получает отметку, прежний сразу теряет кнопки управления.
- Правила переключаются без reload; на mobile раскрыт один раздел. Все шесть исходных текстов сравнены с версией v11 и совпадают.
- На всех внутренних страницах проверены заголовки, отсутствие горизонтального переполнения и загрузка тематических изображений. scroll-behavior — auto, scroll-snap-type — none. Прокрутка не перехватывается JavaScript.

Проверка проведена в локальном браузере. Физическое ощущение колеса мыши и инерции конкретного тачпада зависит от устройства и настроек ОС; приложение не добавляет собственных множителей или инерции. Тестовые команды/сессии хранятся только в браузере preview и не входят в архив исходников.

## Запуск

`npm install`, затем `npm run dev`. Адрес: http://localhost:5173.
Backend отсутствует: используется существующий общий локальный источник данных, приглашения и уведомления сохраняются в браузере.
