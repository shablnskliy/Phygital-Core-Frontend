# Phygital Core — итерация 13

Правки 169–174. 7 октября 2026 года.

## Изменено

- Общий PageHeader: цельный светлый текст вместо разделения слова на заливку и контур. Нет background-clip текста, градиента, text-stroke, размытия, тени, filter или transform заголовка. Вес 800, letter-spacing −0.025em, line-height 1.18 (mobile 1.16), запас снизу, overflow visible.
- Убраны сюжетные изображения из внутренних PageHeader. Для турниров, команд, правил, FAQ, контактов и профиля создана единая серия из шести изолированных декоративных объектов с настоящей прозрачностью.
- Сохранены индекс, описание, лёгкие SVG-линии, сетка, точки и медленное фоновое движение. Объекты вписаны через object-fit: contain без маски, обрезающей края. На mobile композиция идёт под текстом.
- PNG 512×512 и WebP с alpha сохранены в public/page-objects. WebP каждого объекта занимает 30–55 КБ. Исходные изображения остаются нетронутыми; старые ассеты сохранены, но не используются в PageHeader.
- Главная, Header сайта, Footer, карточки турниров, формы, приглашения, уведомления и данные не изменялись.

## Проверки

- Production build, TypeScript и ESLint проходят.
- Турниры, Команды, Правила, FAQ и Контакты проверены на 1920, 1440, 1366, 1024, 768 и 390 px. Заголовки помещаются, не пересекаются с объектами, горизонтального переполнения нет; WebP загружаются.
- В авторизованном профиле проверены новый объект и заголовок после загрузки сессии.
- Проверены alpha-канал всех PNG (диапазон 0–255) и единый размер 512×512.
- Снимки desktop и mobile: docs/preview-v13. Эта итерация не включает повторный полный функциональный тест: бизнес-логика не изменялась.

## Генерация

Использован встроенный image_gen. Промпты и темы каждого объекта: [PAGE-OBJECT-PROMPTS.md](PAGE-OBJECT-PROMPTS.md). Последующая обработка — только пропорциональное уменьшение и кодирование PNG/WebP с сохранением alpha.

## Запуск

`npm install`, затем `npm run dev`. Адрес: http://localhost:5173 (при занятом порте используется следующий доступный).
